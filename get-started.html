From clone to boot

Build it. Boot it.
Watch it panic honestly.

Everything here runs on a real macOS host cross-compiling real x86_64 Mach-O, booted under QEMU. No hidden steps, no closed-source pieces required.

Host toolchain

macOS with Xcode (clang + ld64 are inherently multi-arch, so cross-compiling x86_64 Mach-O from an arm64 host needs no separate cross-toolchain).

QEMU + OVMF

Homebrew's qemu package, for both the emulator and the edk2 OVMF UEFI firmware the bootloader runs under.

No real Catalina SDK needed

The build clones a local SDK from the host's own SDK and header-patches it — build/SDKs/MacOSX10.15.sdk.

Step by step

Building the kernel

1

Build ctf tools & install headers

build-kernel.sh builds the ctf tools, installs AvailabilityVersions/libplatform headers, and builds libfirehose_kernel.a before touching xnu itself.

2

Run the build

# from the repo root
./build-kernel.sh

Runs exporthdrs followed by the kernel proper into build/kernel/kernel.development. A full clean rebuild (with BUILD/ deleted first) exits 0 with zero make-error markers.

3

Verify the output

file build/kernel/kernel.development
# → Mach-O 64-bit executable x86_64

nm build/kernel/kernel.development | grep -E '_pstart|_vstart'
# → both present
Power it on

Booting in QEMU

Once the bootloader and root filesystem images exist under boot/, this is the whole command.

qemu-system-x86_64 -machine q35 -m 2048 \
  -cpu Haswell \
  -bios <ovmf firmware from Homebrew qemu> \
  -drive format=raw,file=<ESP image with bootloader + kernel> \
  -serial stdio

-cpu qemu64 will not work — it fails xnu's own CPU vendor/family check before the kernel gets anywhere. -serial stdio is how every bug on the roadmap page was actually diagnosed: kernel kprintf output goes to serial, while userspace stdout goes to the GOP framebuffer console instead.

Where things live

Repo layout

src/ — pinned checkouts: xnu, dtrace, AvailabilityVersions, libplatform, libdispatch, Libsystem, llvm-project
build/ — all build output; build/SDKs/ holds the local header-patched SDK
boot/ — the custom EFI bootloader source
userland/ — libc, dyld, libSystem, libobjc, CoreFoundation, Foundation, libdispatch, launchd
patches/ — one markdown file per kernel source patch, numbered, self-contained
docs/ — architecture.md: every design decision, and why
logs/ — build and boot logs
TODO.md — the authoritative, currently-maintained phase-by-phase status
